# M08 — AI Security & Governance

Dieses Modul behandelt Sicherheits- und Governance-Grenzen für KI-Systeme: Prompt Injection, Tool Poisoning, Exfiltration, Excessive Agency, Credential Boundaries, Least Privilege, Approval, Audit und regulatorische Grundlagen.

Die vollständige Modulbeschreibung mit Vorstellung, Beispiel, Trainingserfolg, Übungen und Lösungen steht in [`ROADMAP.md`](../../ROADMAP.md#M08--AI-Security--Governance).

## Modulstruktur

- `README.md` — Einstieg und Modulübersicht
- `examples/` — Angriffsszenarien und Policy-Beispiele
- `exercises/` — Red-Team-Aufgaben
- `solutions/` — Referenz-Gegenmaßnahmen
- `evidence/` — Threat Model, Tests und Policy-Nachweise

## Definition of Done

Dokumentiertes Threat Model, Red-Team-Suite und technische Policy Enforcement mit nachvollziehbarem Audit-Verhalten.

## Wissenstest

Der modulbezogene Multiple-Choice-Test mit Fragen, Antwortmöglichkeiten, richtigen Antworten und Erklärungen liegt in [`assessment/quiz.json`](assessment/quiz.json). Das Learning Studio übernimmt diese Datei direkt. Mindestens drei von vier richtigen Antworten sind zum Bestehen erforderlich; praktische Evidence und Review bleiben separate Nachweise.
