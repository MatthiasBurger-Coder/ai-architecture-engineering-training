# Referenz: RAG Engineering Capstone

Referenzaufbau: Source → Parse/Normalize → Version/ACL → Chunk → Embed/Index → Query Auth → Lexical/Dense → RRF/Rerank → Context + Provenance → Generator → Validation. Entscheidungsdokument mit Metriken und Rest-Risiken; CG-Adapter bleibt ein zukünftiger Integrationsschritt.
