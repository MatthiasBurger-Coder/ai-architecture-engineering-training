# Referenz: Lexical vs Dense vs Hybrid

TF-IDF liefert lexikalische Baseline, Word-Hash-Vektoren nur mathematische Demonstration; RRF mischt Ränge statt uneinheitliche Scores. Richtige Lösung ist nicht zwingend hybrid: wähle das auf einem unabhängigen, ausreichend großen Golden Set gemessene Verfahren. Beim Korpus mit nur sechs Queries keine verallgemeinerbaren Produktionswerte behaupten.
