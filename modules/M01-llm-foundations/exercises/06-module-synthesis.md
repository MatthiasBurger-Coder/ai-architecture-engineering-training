# Übung 06 — M01-Syntheseprüfung

Entwirf für den Use Case „Ein Operator möchte einen fehlerhaften Service analysieren und gegebenenfalls neu starten“ eine vollständige Mini-Architektur.

Deine Abgabe muss enthalten:

1. eine Token-/Kontextschätzung;
2. die benötigten Evidence-Quellen;
3. einen LLM-Output als typisiertes Proposal;
4. mindestens drei deterministische Prüfungen;
5. eine klare Restart-Policy mit Approval-Gate;
6. eine Verifikations- und Auditspur;
7. eine Liste von mindestens fünf möglichen Fehlermodi.

Verwende das Format `Proposal → Validation → Evidence → Policy → Execution → Verification` und begründe jede Grenze.
