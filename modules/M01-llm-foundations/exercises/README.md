# Übungen

Bearbeite die Aufgaben in der angegebenen Reihenfolge. Jede Aufgabe hat ein erwartetes Artefakt, das nach `evidence/` kopiert oder dort referenziert wird.

| Aufgabe | Fokus | Abgabe |
|---|---|---|
| 01 | Systemmodell und Lebenszyklus | Diagramm + Erklärung |
| 02 | Self-Attention | vollständige Rechnung |
| 03 | Context Window | Budgettabelle + Entscheidung |
| 04 | Decoding | Messprotokoll mit 30 Samples je Konfiguration |
| 05 | Architekturgrenze | klassifizierte Prozesskette + Policy-Grenze |
| 06 | Syntheseprüfung | vollständiger Mini-Use-Case |

Die Aufgaben prüfen Verständnis und Engineering-Urteil. Eine bloße Definitionen-Sammlung genügt nicht. Übung 06 ist die modulinterne Abschlussprüfung.
