# M05 — Context Engineering

Dieses Modul behandelt Context als bewusst konstruiertes Laufzeitartefakt: Task, State, Evidence, History, Tools und Policies innerhalb eines definierten Budgets.

Die vollständige Modulbeschreibung mit Vorstellung, Beispiel, Trainingserfolg, Übungen und Lösungen steht in [`ROADMAP.md`](../../ROADMAP.md#M05--Context-Engineering).

## Modulstruktur

- `README.md` — Einstieg und Modulübersicht
- `examples/` — Context-Assembly-Beispiele
- `exercises/` — Aufgaben
- `solutions/` — Referenzlösungen
- `evidence/` — Messungen zu Qualität, Tokenverbrauch und Latenz

## Definition of Done

Context Builder mit reproduzierbarer Auswahlentscheidung, Budget Enforcement und dokumentiertem Vergleich von Minimal-, Maximal- und adaptiver Strategie.

## Wissenstest

Der modulbezogene Multiple-Choice-Test mit Fragen, Antwortmöglichkeiten, richtigen Antworten und Erklärungen liegt in [`assessment/quiz.json`](assessment/quiz.json). Das Learning Studio übernimmt diese Datei direkt. Mindestens drei von vier richtigen Antworten sind zum Bestehen erforderlich; praktische Evidence und Review bleiben separate Nachweise.
