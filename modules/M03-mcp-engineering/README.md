# M03 — MCP Engineering

Dieses Modul behandelt MCP praktisch: Host, Client, Server, Discovery, Tools, Transport, Authentifizierung und API→MCP-Mapping.

Die vollständige Modulbeschreibung mit Vorstellung, Beispiel, Trainingserfolg, Übungen und Lösungen steht in [`ROADMAP.md`](../../ROADMAP.md#M03--MCP-Engineering).

## Modulstruktur

- `README.md` — Einstieg und Modulübersicht
- `examples/` — Protokoll- und Mapping-Beispiele
- `exercises/` — Aufgaben
- `solutions/` — Referenzlösungen
- `evidence/` — Contract-, Integrations- und Fehlerfallnachweise

## Definition of Done

Eigener MCP Server + eigener Client + mindestens drei Tools + dokumentiertes Upstream-Mapping + automatisierte Tests.
