# M02 — Structured Output & Tool Calling

Dieses Modul verbindet probabilistische Modellentscheidungen mit typisierten Softwareverträgen: Structured Outputs, JSON Schema, Tool Contracts, Validation und Side-Effect-Klassen.

Die vollständige Modulbeschreibung mit Vorstellung, Beispiel, Trainingserfolg, Übungen und Lösungen steht in [`ROADMAP.md`](../../ROADMAP.md#M02--Structured-Output--Tool-Calling).

## Modulstruktur

- `README.md` — Einstieg und Modulübersicht
- `examples/` — Beispiele und Diagramme
- `exercises/` — Aufgaben
- `solutions/` — Referenzlösungen
- `evidence/` — Nachweise für die Acceptance Criteria

## Definition of Done

Abgeschlossen bei drei produktionsnahen Tool Contracts inklusive Tests, Permission Metadata und dokumentierter Evidence.
